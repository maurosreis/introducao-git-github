# Introdução ao Git e GitHub

Material de apoio ao curso introdutório de Git e GitHub da disciplina. O curso apresenta os conceitos de controle de versão e ensina, passo a passo, como usar essas ferramentas para organizar, acompanhar e compartilhar projetos.

## Sobre o curso

Ao desenvolver um programa ou outro projeto, modificamos arquivos várias vezes. Sem um registro dessas mudanças, pode ser difícil descobrir o que foi alterado, recuperar uma versão anterior ou colaborar com outras pessoas.

O Git é um sistema de controle de versão que registra a evolução dos arquivos de um projeto. O GitHub é uma plataforma on-line que hospeda repositórios Git e oferece recursos para compartilhar projetos e colaborar.

Neste curso, vamos estudar esses conceitos e praticar o uso das ferramentas desde os primeiros passos.

## Objetivos do curso

Ao final do curso, espera-se que o estudante consiga:

- Compreender o que é versionamento de software e como ele registra a evolução de um projeto
- Entender a importância do controle de versão para acompanhar alterações, recuperar versões anteriores e colaborar com outras pessoas
- Conhecer os conceitos fundamentais do Git e sua diferença em relação ao GitHub
- Instalar e configurar o Git, incluindo nome de usuário e e-mail
- Compreender o funcionamento básico de um repositório e o ciclo de trabalho do Git
- Criar repositórios locais e remotos
- Registrar alterações usando os comandos `add` e `commit`
- Consultar o histórico de alterações
- Conectar um repositório local ao GitHub e enviar alterações com `push`
- Obter uma cópia de um repositório com `clone` e atualizá-la com `pull`
- Editar e organizar arquivos de um projeto no GitHub
- Utilizar o GitHub para compartilhar projetos e acompanhar os materiais do curso
- Conhecer noções iniciais de colaboração, incluindo branches e pull requests
