# Atividade da Aula 1 — Meu primeiro repositório

1. Crie um repositório no GitHub com um nome simples.
2. Adicione um arquivo `README.md`.
3. Escreva o objetivo do repositório e uma frase sobre o que espera aprender sobre Git.
4. Confira a visibilidade e os arquivos antes de compartilhar.
5. Entregue o endereço do repositório conforme a orientação do professor.

## Questões de revisão

1. O que significa versionar um projeto?
2. Cite dois problemas de manter várias cópias de arquivos com nomes como `final2` e `final_corrigido`.
3. Qual é a diferença entre Git e GitHub?
4. O que é um commit?
5. Por que é importante verificar os arquivos antes de publicar um repositório?
